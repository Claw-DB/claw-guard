# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately to the maintainers before opening a public issue.

Include:

- A description of the issue and affected component.
- Reproduction steps or a minimal proof of concept.
- Impact assessment and any suggested mitigation.

Maintain confidentiality until a fix is available and a coordinated disclosure date is agreed.

## Supported Versions

Only the latest published release is supported with security fixes.
